# 0018: 0015の対策のあとも、合間の報告を英語で書いた

- 日付: 2026-11-09
- ステータス: 対策の判断待ち(仕組みの対策をどうするかを、メンテナーに確かめている)
- 関連: [0001](0001-english-text-shown-to-maintainer.md)、[0005](0005-english-notes-between-tool-calls.md)、[0015](0015-english-reports-after-stop-hook.md)(同じ種類の異常の再発)

## 起きたこと

2026-11-09に、v0.2.0の版を上げる作業の途中で、エージェントは、ツール呼び出しの合間に「Next: bump the version and run the dependency age check.」と表示した。次に何をするかの報告で、AGENTS.mdでは日本語で書くもの(メンテナーへの説明・報告)にあたる。エージェントが、同じターンのうちに気づき、作業を止めてメンテナーに報告した。

確かめた事実(このセッションの会話の記録。assistantの文のうち、ラテン文字を含み、ひらがな・カタカナ・漢字を含まないものを検索した):

- 0015の対策(2026-11-05)のあと、日本語を含まない文は2つあった。
  - 2026-11-09 23:03(JST): 上の文。直前は、ツールの結果(コマンドの出力)と、英語のシステムの通知(タスクの道具の案内)だった。同じターンの、この文の前後の合間の報告は日本語だった。
  - 2026-11-09 23:20(JST): ワーカーのプロセスの再起動の通知への返答「No response requested.」。この返答は、再起動の通知と同じ時刻(ミリ秒まで同じ)に記録されていて、Stopのフック(`require-japanese-reply.sh`)は動いていない。エージェントが書いたものか、実行環境が加えたものかは、確かめられなかった。
- このセッションの記録の始まり(2026-11-01)から0015の対策(2026-11-05)までには、同じ種類の文が、メモと報告を合わせて75件あった(日ごとに24、22、12、15、2件。例:「Now create the PR, the summary comment, and subscribe.」)。0015の対策のあとは、上の2件だけである。
- ツール呼び出しの合間の文を確かめる仕組みはない。0005で加えたフック(合間の文に日本語がなければ、次のツールの呼び出しを拒否する)は、2026-11-01のメンテナーの判断で削除した。その判断では、合間の短いメモがやむを得ず英語になることを許容し、メンテナーへの説明・報告は必ず日本語で書くとした。
- 0015の対策1(振る舞い)は、メンテナーへの説明・報告は短くても日本語で書き、迷ったら日本語で書く、とした。仕組みの対策は、Stopのフックの変更だけだった。

## なぜなぜ分析

| なぜ | 答え(確かめた事実) |
| --- | --- |
| なぜ英語の報告が表示されたか | エージェントが、次の作業を告げる短い文を英語で書いたため |
| なぜ英語で書いたか | 英語の入力(ツールの結果とシステムの通知)が続いた直後に、短い文を書いたため。前後の報告は日本語で、規則は知っていた(入力の言語に引きずられたというのは推測) |
| なぜ表示のあとも止まらなかったか | ツール呼び出しの合間の文を確かめる仕組みがないため。0005のフックは、短いメモの英語を許容するという判断で削除し、0015でも規則だけで対応した |
| なぜ規則だけでは防げないか | 規則は書くときに思い出す必要があり、短い文ほど、メモ(英語でもよい)と報告(日本語)の区別を意識しないまま書くため。0005と0015で、同じことが繰り返し確かめられている |

## 真因

ツール呼び出しの合間の報告を日本語で書くことを、規則だけに頼っている。メモと報告の境目は、書く時点で区別されにくい。

## 対策

1. 現象への対応: その場でメンテナーに報告し、以後の報告を日本語で書いた。
2. 仕組み: メンテナーの判断を待っている(下の選択肢)。0005で削除した種類のフックを戻すことになるため、2026-11-01の判断との関係を示して確かめる。
   - フックを戻す: ツール呼び出しの前に、そのツール呼び出しを含むメッセージの文を会話の記録(`transcript_path`)から読み、ラテン文字を含み日本語を含まなければ、呼び出しを拒否して書き直しを求める。記録の中は、入力の`tool_use_id`で探し、見つからなければ止めない(0005で、記録は非同期に書かれ最新のメッセージを含まないことがあるとして採らなかった点への対応)。文は一度は表示される。短いメモも日本語で書くことになる。
   - 規則のまま: 2026-11-01の判断を保つ。同じ種類の再発は、そのたびに止めて報告する。
3. 規則: 2の判断に合わせて、AGENTS.mdの言語ルールの原則を見直す。

## 確かめ方

- 2の判断のあとに決める。フックを戻す場合は、`scripts/check_hooks.py`のサンプル入力(日本語を含まない文で拒否し、日本語を含む文と、記録にないツール呼び出しで通す)と、実際のセッションでの動作で確かめる。
