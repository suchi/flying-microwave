# 将来のオプションのアイデア

- 作成日: 2026-10-31
- ステータス: アイデア集。採否・優先度は各フェーズの計画時にメンテナーが決める。採用したものは実装計画と設定項目仕様に移す。
- 関連: [実装計画](../plans/0001-initial-implementation-plan.md)、[設定項目仕様](../design/settings.md)、[ビジュアルデザイン方針](../design/visual-design.md)

## 前提となる制約

| 制約 | 内容 | 根拠 |
| --- | --- | --- |
| 入力はすべて終了に使う | `/s`の実行中はキーやマウスの入力で必ず終了するため、隠しコマンドを`/s`中の入力で発動させることはできない。発動のきっかけは日時・確率・設定画面・プレビューに限る。単独アプリとしての実行([ADR-0012](../adr/0012-standalone-app-mode.md))では入力で終了しないため、入力をきっかけにする隠し要素も考えられる | [仕様調査](../research/windows-screensaver.md)のW-4 |
| 通信しない | 天気・ニュースなどネットワークが必要な情報は使わない | [アーキテクチャ](../design/architecture.md)のA-4 |
| 実行中に書き込まない | 累計稼働時間のように`/s`中の状態保存が必要なものは、設計上の例外として個別に判断する | アーキテクチャのA-5 |
| 表現上のガイドライン | 着想元の要素を使わない、危険な使い方を肯定しない、閃光を使わない、静止要素を置かない | [ビジュアルデザイン方針](../design/visual-design.md)のG-1〜G-6 |
| 日付の裏付け | 記念日などの日付は、実装前に一次情報で確認する | AGENTS.mdの情報源の方針 |

## 時間的に変化する項目

| ID | アイデア | 実装メモ | 懸念・制約 | 優先度案 |
| --- | --- | --- | --- | --- |
| T-01 | LED表示に現在時刻を出す | 実物の電子レンジが待機中に時計を出すことにちなむ。`core`に時刻を注入してテストする | 12時間・24時間表示の設定 | 高(実装計画のv0.3.0に含めた) |
| T-02 | 時間帯で背景の色味が変わる(夜明け・昼・夕方・夜) | 時刻から色を補間する純粋関数として実装する | 明るくしすぎない(G-5) | 高 |
| T-03 | 時間帯で飛ぶ食べ物が変わる(朝はマグカップ、昼は弁当、夜は肉まんなど) | テーマ選択の表に時刻の条件を加える | 地域による食文化の違い | 中 |
| T-04 | 季節・行事のテーマ(正月、バレンタイン、ハロウィン、クリスマスなど) | 日付範囲とテーマの対応表を`core::theme`に持ち、日付を与えてテストする | 文化的な偏りに配慮し、設定でオフにできる(G-6) | 高 |
| T-05 | 大晦日のカウントダウン。12月31日23時59分からLEDが残り秒数を表示し、0時に全機が一斉に加熱完了の表示を出す | 時刻注入で境界のテストを書く | 一斉演出で閃光を使わない(G-3) | 中 |
| T-06 | タイマーのカウントダウン。各電子レンジのLEDがタイマーを表示し、0になると加熱完了の表示とともにドアが開いて食べ物が飛び出す | 電子レンジごとにタイマーの初期値を乱数で決める | T-01の時計表示との切り替え方 | 高 |
| T-07 | 長時間の稼働で「保温モード」になり、ゆっくり・少し暗くなる | 起動からの経過時間を使う | 省電力・焼き付き対策にもなる | 中 |
| T-08 | 金曜の夜はポップコーンが多い「映画の夜」 | 曜日と時刻の条件 | - | 低 |
| T-09 | 夜空の月の満ち欠け | 月齢は日付から計算でき、通信は不要 | 計算式の出典を確認する | 低 |
| T-10 | ぞろ目の時刻(11:11、12:34など)に全機のLEDがそろう | T-01の拡張 | - | 低 |
| T-11 | 解凍モード。冷凍食品が霜をまとって出現し、飛ぶうちに解凍されていく | 1回の飛行の中で見た目が変化する | 素材の追加が必要 | 低 |
| T-12 | 日の出・日の入りに合わせた背景 | 位置情報が必要になるため、地域を手動で設定する場合に限る | プライバシー。位置を自動取得しない | 低(要検討) |

## 隠し要素(イースターエッグ)

| ID | アイデア | 発動のきっかけ | 懸念・制約 | 優先度案 |
| --- | --- | --- | --- | --- |
| E-01 | 金色の電子レンジ | 出現のたびにごく低い確率 | 確率は設定画面の開発者表示で確認できるようにする | 高 |
| E-02 | ダイヤル式の古い電子レンジがまれに混ざる | 確率 | 素材の追加が必要 | 中 |
| E-03 | 炊飯器・冷蔵庫など家電の仲間がまれに一緒に飛ぶ | 確率 | トースターは使わない(G-1) | 中 |
| E-04 | 編隊飛行。まれに隊列を組み、矢印などの形で飛ぶ | 確率 | 隊列の生成と崩し方の設計 | 中 |
| E-05 | すれ違うと加熱完了の吹き出しであいさつする | 2機が近づいたとき | 頻度が高すぎると煩わしい | 低 |
| E-06 | 4月1日は全機が逆向きに飛ぶ | 日付 | - | 中 |
| E-07 | 設定画面のAboutにあるロゴを7回クリックすると開発者表示(FPS、フレーム時間、機数)を有効にできる | 設定画面の操作 | 動作確認・性能計測にも役立つ | 高 |
| E-08 | まれにLEDが「HOT」表示になり、湯気を出しながら飛ぶ(温めすぎ) | 確率 | - | 低 |
| E-09 | プレビュー枠(スクリーンセーバーの設定画面の小さなモニタ)でだけ見られる小さな演出 | `/p`のときのみ | - | 低 |
| E-10 | 誕生日に登録した日はケーキが飛ぶ | 日付(設定で登録) | 個人情報はローカルの設定ファイルにのみ保存し、通信しない | 低 |
| E-11 | 累計稼働時間に応じた実績(例: 累計100時間で金色が出やすくなる) | 累計稼働時間 | `/s`中の書き込みが必要でA-5の例外になる。終了時に1回だけ書くなどの設計が必要 | 低(要検討) |
| E-12 | 隠しの起動オプション(例: `/s --demo`)で、全演出を短時間で順番に見せる | コマンドライン引数 | デモと手動テストの効率化にも使える。Windowsは付けないため通常利用に影響しない | 高 |
| E-13 | 電子レンジの発明にちなむ日の特別演出 | 日付 | 日付を一次情報で確認してから実装する | 低 |
