# v0.2.0-alpha.1の実機での確認の手順

- 作成日: 2026-11-04
- 対象: 試作版`v0.2.0-alpha.1`。電子レンジの絵と設定画面を実機で見るための、短い確認([計画0004](../plans/0004-v0.2.0-settings.md)のD-6)。v0.2.0の正式なリリースの前の確認(計画0001の8.2の手動テスト。計画0004の作業9で、v0.2.0の項目を加える)とは別である。
- 結果: 下の「結果」の節。

手順の記号(P-1、A-2など)は本書の中だけのもので、アーキテクチャの決まりや[v0.1.1の手順](hardware-check-v0.1.1.md)の記号とは別である。

以下は、メンテナーに渡した手順と同じ内容である。

対象: GitHub Releaseの下書き`v0.2.0-alpha.1`の`FlyingMicrowave-0.2.0-alpha.1-windows-x64.zip`。電子レンジの絵と設定画面を、実機で見るための確認です。細部の不具合は残っている前提で、気になった点は雑な一言で返してください。

結果は、番号ごとに「OK」「NG(見えたこと)」「できなかった」で返してください。最後に、ログ(手順Z)も送ってください。

## 準備

- P-1. 下書き`v0.2.0-alpha.1`からzipをダウンロードし、エクスプローラーの「すべて展開」で、前の版とは別の新しいフォルダ(例: `%LOCALAPPDATA%\Programs\FlyingMicrowave-0.2.0a1`)に展開する。
  展開の前に、PowerShellの`Get-FileHash <zipのパス> -Algorithm SHA256`のHashが`24D7AABCF7D4963723E3164CFCE54B59FB8D4C9AA2813077541AEB871934B09E`であることを確かめる。
- P-2. 展開した`FlyingMicrowave.scr`を右クリックし、「インストール」を選ぶ(Windows 11では「その他のオプションを確認」の中)。スクリーンセーバーの設定の画面が開き、「FlyingMicrowave」が選ばれていること。
- P-3. 前のログを消す。

  ```powershell
  Remove-Item $env:TEMP\flying-microwave.log -ErrorAction SilentlyContinue
  ```

## A. 電子レンジの絵

- A-1. プレビュー枠: 設定の画面の小さなモニタの絵の中で、立体的な電子レンジが飛んでいる。
- A-2. 全画面: 「プレビュー」ボタンを押す。成功の見え方:
  - 濃い紺色の背景の上を、斜め上から見た箱形の電子レンジが、少し傾いて、右上から左下へ流れていく。
  - 本体の色が4種類ある(シルバー、グラファイト=濃い灰色、ホワイト、ミント=薄い緑)。
  - ドアが左側を軸にして、1秒に1〜2回ほど開いたり閉じたりしている(羽ばたき)。
  - ドアの窓から、オレンジ色に光る庫内と、皿の上のティール色のマグカップが見える。
  - 右側の操作パネルに、ティール色の「12:34」の表示がある(固定の表示で、時刻ではない)。
  - 四角を組み合わせた古い仮の図形ではない。
- A-3. キーを押して終わらせる。画面がすぐに消えること。
- A-4. 見た目について、気になった点(大きさ、速さ、色、ドアの動き、ちらつきなど)を一言で。

## B. 設定画面

- B-1. 設定の画面で「設定」を押す。成功の見え方: 暗い色の「Flying Microwave Settings」という画面が、設定の画面の手前に開く。上に「Flying Microwave」、その下に Flight・Display・About のタブ、下に Defaults(左)と OK・Cancel(右)。
- B-2. 設定画面が開いている間、後ろの設定の画面をクリックしても反応しない。
- B-3. Flight で「Number of microwaves」を3に、「Size」を2.0に変えて OK を押す。設定画面が閉じ、後ろの設定の画面が前面に戻る(戻らなければ、そのことを書く)。
- B-4. 「プレビュー」を押す。成功の見え方: 電子レンジが3個だけで、前より大きい。キーで終わらせる。
- B-5. もう一度「設定」を開き、B-3で変えた値が残っていること。Display で「Monitors」を「Primary only」にして OK(モニタが2台以上ある場合)。「プレビュー」を押し、主モニタだけで電子レンジが飛び、ほかのモニタは黒いこと。キーで終わらせる。
- B-6. 「設定」を開き、Defaults を押してから OK を押す。値が既定(12個、Speed 1.00、Size 1.00、60 fps、All monitors、Medium)に戻ること。
- B-7. 「設定」を開いて Cancel を押す。値が変わらずに閉じること。
- B-8. 設定画面の見た目について、気になった点(配置、文字の大きさ、色)を一言で。拡大率(ディスプレイの設定の「拡大/縮小」)が150%などの環境なら、崩れていないかも。

## C. 待ち時間での起動

- C-1. 待ち時間を1分にして「適用」し、触らずに待つ。1分ほどで全画面になり、A-2と同じ絵が見えること。キーで終わらせる。確かめたら、待ち時間を元に戻す。

## Z. ログを送る

- Z-1. 次を実行し、出力を送る。ユーザー名などは伏せてかまいません。

  ```powershell
  Get-Content $env:TEMP\flying-microwave.log
  ```

## 後片付け
