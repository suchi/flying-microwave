# v0.3.0-alpha.3の実機での確認の手順

- 作成日: 2026-11-13
- 対象: 試作版`v0.3.0-alpha.3`(タグはPR #79のマージのコミット`1cdbc2f`)。[計画0005](../plans/0005-v0.3.0-visuals-and-clock.md)の作業10の確認で、D-18で作業8(`alpha.2`)から移した項目を含む。F-01の原因を調べる仕組み(作業10の2)は、この版には含まれない(D-19)。
- 結果: まだ受け取っていない。

手順の記号(P-1、A-2など)は本書の中だけのもので、ほかの手順書の記号とは別である。

以下は、メンテナーに渡した手順と同じ内容である。

対象: GitHub Releaseの下書き`v0.3.0-alpha.3`の`FlyingMicrowave-0.3.0-alpha.3-windows-x64.zip`。3Dの電子レンジの見た目と動き、LEDの時計、一緒に飛ぶ食べ物を、実機で見るための確認です。結果は、番号ごとに「OK」「NG(見えたこと)」「できなかった」で返してください。値を決める項目(A-2など)は、「このままでよい」か「もっと遅く」のような一言で構いません。最後に、ログ(手順Z)も送ってください。

## 準備

- P-1. 下書きの`v0.3.0-alpha.3`を、プレリリースとして公開する(「Set as a pre-release」のまま「Publish release」)。
- P-2. 公開したリリースからzipをダウンロードし、ハッシュを確かめる。coreutilsの入ったcmdで、ダウンロードしたフォルダで次を実行する。

  ```bash
  sha256sum FlyingMicrowave-0.3.0-alpha.3-windows-x64.zip
  ```

  期待する表示は`cd2e01d648bcd77f8acf78d1216d00a81ec3e6115512fbe8ecfb456616cfca9e  FlyingMicrowave-0.3.0-alpha.3-windows-x64.zip`。一致しないときは、先に進まずに知らせてください。
- P-3. エクスプローラーの「すべて展開」で、前の版とは別の新しいフォルダに展開し、`FlyingMicrowave.scr`を右クリックして「インストール」を選ぶ(Windows 11では「その他のオプションを確認」の中)。スクリーンセーバーの設定の画面で「FlyingMicrowave」が選ばれていること。
- P-4. 設定ファイルを既定に戻すため、設定画面(設定の画面の[設定])で「Defaults」を押してから「OK」を押す。
- P-5. 前のログを消す(cmdで実行する)。

  ```bash
  del %TEMP%\flying-microwave.log
  ```

## A. 3Dの見た目と動き(E-1、G-3、D-12)

設定の画面の「プレビュー」ボタンで全画面にし、1〜2分見てください。

- A-1. 成功の見え方: 濃い紺色の背景の上を、立体的な電子レンジが、それぞれ違う向きで回転しながら、右上から左下へ飛ぶ。奥のものほど小さく、ゆっくり見える。ドアがヒンジの回りに開いたり閉じたりし、庫内のターンテーブルが回る。
- A-2. 値の判断(一言で): 回転の速さ(速すぎる、遅すぎる、このままでよい)、既定の大きさ、飛ぶ速さ、手前と奥の分かれ方。
- A-3. 回転による明るさの変化(G-3): 面の明るさが変わるとき、点滅のようにちらついて見えないこと。
- A-4. 縁: 電子レンジの縁のギザギザが、気になるかどうか(気になるなら、なめらかにする処理を加えることを検討する)。遠くで斜めを向いたドアの縁が、欠けて見えないこと。

## B. 飛び方の選択(手動テストの項目30)

- B-1. 設定画面の Flight のタブに、Flight style の行(Tumbling と Level)があり、ほかの行やボタンと重ならない。
- B-2. Level を選んで OK を押し、全画面にする。すべての電子レンジが同じ向き(正面、右の側面、上面が見える向き)で飛ぶ。設定の画面のプレビュー枠も同じになる。
- B-3. Tumbling に戻して OK を押す。それぞれ違う向きで回転しながら飛ぶ。

## C. LEDの時計(手動テストの項目31)

- C-1. 全画面で、電子レンジの正面のLEDに、PCの時計と同じ時刻(時と分)が出て、コロンが1秒ごとに点滅する。分が変わると、表示も変わる。
- C-2. 設定画面の Display のタブで Clock format を 12-hour にして OK を押す。午前は「 9:05」のように十の位の0が出ない。午後は左下の点が光る。
- C-3. Show clock on display をオフにして OK を押す。LEDの画がすべて消えた表示(薄い「88:88」)になる。確かめたら、オンと 24-hour に戻す。

## D. 左の側面、上面、底面の絵(手動テストの項目32)

- D-1. 回転して飛ぶ電子レンジの、左の側面に通気口(正面に近い側)、上面に縁の継ぎ目、底面に4つの脚と銘板が見える。
- D-2. Size を 2.0 にして全画面にし、手前の大きな電子レンジで、この3面が、正面や右の側面と比べて気になるほどぼやけていないかを見る。確かめたら、Size を 1.0 に戻す。

## E. 飛ぶ食べ物(手動テストの項目33)

- E-1. 設定画面の Flight のタブに、Number of food items の行(0〜30のスライダー、既定4)がある。
- E-2. Number of food items を30にして OK を押し、全画面にする。弁当(黒いトレーと、ふた越しのご飯とおかず)、ポップコーンの袋(赤と白の縞)、マグカップ(青緑で、取っ手と飲み物)、肉まん(白い半球で、頂にひだ)の4種類が見える。どれも電子レンジより小さく、電子レンジと同じく右上から左下へ飛ぶ。
- E-3. 食べ物の大きさの判断(一言で。D-17の(3)の出発点の値): 小さすぎる、大きすぎる、このままでよい。
- E-4. Flight style を Level にすると、食べ物も回転しなくなる。マグカップの取っ手はどれも右に見え、ポップコーンの袋はどれもポップコーンの窓がある面が正面に見え、弁当はどれもふた越しの中身が上に見える。確かめたら、Tumbling に戻す。
- E-5. Number of food items を0にして OK を押す。食べ物は飛ばない。確かめたら、4に戻す。

## F. 終了の速さ(N-02)

- F-1. 全画面で、キーを押す。画面が、もたつかずに一瞬で消えること(数値は実機では測れないため、目で見た判定と、CIの値を合わせて記録する)。何回か試し、一度でも0.5秒ほど残ったら、そのことを書く。

## G. 負荷とメモリ(N-03、N-04)

- G-1. 既定の設定で全画面にし、5分間そのままにする。別のPC(またはスマートフォン)で時間を計り、終わる直前の様子を見る必要はありません。全画面の前にタスクマネージャーを開いておき、全画面を終えた直後に、「詳細」のタブの`FlyingMicrowave.scr`の行が消える前の値を見ることは難しいため、次の方法にします: タスクマネージャーの「パフォーマンス」ではなく、全画面の前に「詳細」のタブを開き、列に「CPU」と「メモリ(アクティブなプライベート ワーキング セット)」を表示しておく。設定の画面の「プレビュー」で全画面にし、5分後にマウスを動かさずに Alt+Tab でタスクマネージャーに切り替えて値を読む(切り替えで全画面が終わる場合は、終わる直前の値として読めた範囲で書く)。
- G-2. 書くこと: CPU(%)とメモリ(MB)、モニターの解像度とリフレッシュレート、GPUの名前。目安は、CPUが論理1コアの10%以下(N-03。4Kモニター1台、60fps)、メモリが200MB以下で増え続けない(N-04)。

## Z. ログ

- Z-1. 次のファイルを送ってください: `%TEMP%\flying-microwave.log`。起動の速さ(N-01)は、このログの起動の行(`Flying Microwave 0.3.0-alpha.3 started`。`crates/app/src/main.rs`の`run`)から、ウィンドウごとの`first frame presented`の行(`crates/app/src/saver.rs`の`try_draw`)までの時間で、エージェントが読みます。
