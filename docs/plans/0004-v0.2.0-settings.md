# 0004: v0.2.0 設定画面(Phase 2)

- ステータス: 完了(v0.2.0を2026-11-10に公開した)
- 日付: 2026-11-03
- 関連: [計画0001](0001-initial-implementation-plan.md)のPhase 2、計画0001のF-04・F-06・F-07、D-20・D-24・D-27・D-28、[設定項目仕様](../design/settings.md)、[アーキテクチャ](../design/architecture.md)、[ADR-0003](../adr/0003-settings-ui-with-eframe.md)、[ADR-0004](../adr/0004-store-settings-as-toml.md)、[ADR-0011](../adr/0011-license-notices-with-cargo-about.md)、Issue #28・#29・#3

本計画の要件のID(F-xx、N-xx)は本計画のものである。計画0001の要件を指すときは、「計画0001の」を付ける。

## 目的

設定画面から主要なパラメーターを変えられるようにし、`/s`と`/p`に反映する(計画0001のF-06)。計画0001のPhase 2の作業を、実装できる単位に分け、決めることを並べる。

着手の条件: v0.1.1(計画0003)をリリースしていること(計画0001のD-24)。v0.1.1の実機での確認の記録と商標の確認の残り(Issue #47)は、本計画の完了条件で扱う。本計画は、それより前に合意し、v0.1.1のリリースのあとすぐに始められるようにした。

## 範囲

- 対象: [設定項目仕様](../design/settings.md)のv0.2.0の6項目(`flight.count`、`flight.speed`、`flight.scale`、`display.max_fps`、`display.monitors`、`input.exit_sensitivity`)、設定ファイルの読み書き、設定画面(Flight・Display・Aboutのタブ、OK・Cancel・Defaults)、`/s`と`/p`への反映、`/s`の実行中のモニタの変更への対応(計画0001のF-07)。
- 対象外: v0.3.0以降の項目(食べ物、時計、背景、隠し要素)、Extrasのタブ、単独アプリとしての実行(計画0001のF-12)、本番の絵(Phase 3)。

## 要件

| ID | 要件 |

| F-01 | 設定ファイルを読み、[設定項目仕様の検証規則](../design/settings.md#検証規則)のとおりに値を決める。規則の各行をテストにする(`core::config`の純粋関数) |

| F-04 | 設定画面は、Flight・Display・Aboutのタブと、OK・Cancel・Defaultsのボタンを持つ。UIラベルは英語(設定項目仕様のUIラベル)。保存に失敗したら、設定画面の中にエラーを表示する |
| F-05 | Aboutのタブに、版、ライセンス、依存ライブラリのライセンス表記(ADR-0011)、着想元についての説明(IP-1の範囲)、プロジェクトのURLを表示する。隠し要素には触れない。ライセンス表記は、実行ファイルの隣の`THIRD-PARTY-LICENSES.txt`を読んで、スクロールできる領域に表示する(D-12。実装済み: `crates/app/src/licenses.rs`)。読めないときは、その旨とファイル名を示す |
| F-06 | `/s`と`/p`は、起動時に設定を読む。`/s`は6項目を反映する(`display.monitors = "primary"`では、ほかのモニタは黒で覆う)。`/p`は、`flight.*`と`display.max_fps`を反映する(`display.monitors`と`input.exit_sensitivity`は、1つの子ウィンドウで入力を無視する`/p`には当てはまらない)。設定の読み込みで、全画面を黒で覆うまでの時間(計画0001のN-01)を遅らせない |
| F-07 | `/s`の実行中にモニタが追加・変更されても、すべてのモニタを覆う(計画0001のF-07)。実装済み(作業10、D-12)。2画面で2台目に描かれないIssue #50は、描き方を変えて直した(D-14、ADR-0025)。2026-11-09に、`v0.2.0-alpha.4`で、2画面の実機で両方のモニタに描かれることを確かめた(D-14)。モニタの抜き差しと、リフレッシュレートの違うモニタの組み合わせは、未確認 |
| F-08 | 設定ファイルの`schema_version`が新しいときは、読める項目だけを使い、OKで書き込む前に、利用者に確認する。書き込みの形式はE-3で決める |
| F-09 | 設定画面のプロセスにも、SEC-1(DLLの検索パスの制限)とSEC-2(DX12とFxcの明示)を適用する。GPUが使えないときの動作はE-4で決める |
| N-01 | 表示の拡大率(100%、150%など)を変えても、設定画面の配置が崩れない(Issue #29) |
| N-02 | 設定画面の見た目は、配置と余白を整えたものにし、案をメンテナーが確かめてから実装する(計画0001のPhase 2の見た目の要件、Issue #29) |
| N-03 | 新しい依存は、下の決定(D-2・D-3)で承認したものだけにする。公開から7日以上の版を使う(AGENTS.md) |
