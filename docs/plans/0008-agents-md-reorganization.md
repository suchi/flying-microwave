# 0008: AGENTS.mdを原則だけにし、手順を文書へ移す

- ステータス: 合意済み(2026-11-28。D-1〜D-6は、メンテナーが推奨の案で決めた)
- 日付: 2026-11-28
- 関連: [AGENTS.md](../../AGENTS.md)、[docs/development/review-process.md](../development/review-process.md)、[docs/development/onboarding.md](../development/onboarding.md)、[docs/incidents/README.md](../incidents/README.md)、`.claude/commands/`

## 目的

AGENTS.mdは、異常のたびに手順を書き足してきたため、約54,000字(2026-11-28に`wc -m`で数えた)になり、エージェントが毎回読むコンテキストを多く使っている。AGENTS.mdを、守るべき原則と禁止事項に絞り、細かい手順は、それを使う場面の文書(手順の文書とコマンド)に移す。読み手は、2026-11時点の汎用の高性能なモデル(Claude Opus 5.5、Claude Sonnet 5.5、他社の同じ水準のもの)を想定してよい(メンテナーの指示)。

## 決定

| ID | 決定 |
| --- | --- |
| D-1 | 進める順番: AGENTS.mdの整理(この計画)、v0.4.0(D-3、D-4)、v0.5.0(D-5)の順。元のPhase 4(時間で変わる演出)は、そのあとにする |
| D-2 | 整理の形: AGENTS.mdは原則と禁止事項を短く書き、細かい手順は、すでにある手順の文書とコマンドに移して参照する。incidentへの参照も、AGENTS.mdの文の中からは外す(手順の文書の側に残す)。規則の写しの表とそのテスト(`scripts/test_rule_copies.py`)も合わせて直す。目安は、いまの3分の1以下 |
| D-3 | v0.4.0の単独アプリ([ADR-0012](../adr/0012-standalone-app-mode.md)): v0.4.0で出す。zipに同じ中身の`FlyingMicrowave.exe`も入れる。全画面のあいだは、ディスプレイのスリープとスクリーンセーバーの起動を止め、カーソルを隠す(マウスを動かすと数秒だけ出す)。ウインドウ表示ではどちらもしない。ウインドウは毎回1280×720(画面より大きいときは画面に収める)で、画面の真ん中に開き、大きさは保存しない([ADR-0004](../adr/0004-store-settings-as-toml.md)は変えない) |
| D-4 | v0.4.0の複数画面: 複数の画面を1つの空間にするオプションを加え、既定でオンにする。Windowsのすべての画面を囲む四角を1つの空間にし、電子レンジは画面をまたいで飛ぶ。画面のないところを通るあいだは見えない |
| D-5 | v0.5.0の衝突: 電子レンジどうし、食べ物どうし、電子レンジと食べ物のすべてが3Dで衝突する。ぶつかると向きと回転が変わって跳ね返り、数秒かけて元の流れ(右上から左下)に戻る |
| D-6 | 手順の変わらなさ: 整理は書く場所を変えるだけで、規則と手順の中身は変えない。中身を変えたほうがよいものが見つかったときは、整理とは別に、案と質問を示す |

## 作業

1. いまのAGENTS.mdの規則を1つずつ並べ、残す場所(AGENTS.mdの原則、手順の文書、コマンド)を決めた対応表を作る。
2. 新しいAGENTS.mdと、移す先の文書の変更の案を作る。
3. 案の全文と対応表を示して、メンテナーの承認を得る(規則のファイルとセキュリティ設定のファイルの変更のため)。
4. 承認を得た案を適用し、規則の写しの表とテストを直す。
5. 本格的なレビューを受け(規則のファイルのため)、PRを作る。レビューの依頼文には、対応表を渡し、規則の抜けがないかを確かめさせる。
