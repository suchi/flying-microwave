# ビジュアルデザイン方針

- 作成日: 2026-10-31
- ステータス: 採用(2026-10-31)。飛行表現は案Aで進め、Phase 3の素材作成時に見え方を確認する(実装計画のD-9)。Phase 1・2は単純な図形の仮素材で進める。素材の形式は[ADR-0008](../adr/0008-svg-assets-with-resvg.md)に記録した。
- 関連: [先行作品と知的財産上の配慮](../research/prior-art-and-ip.md)、[アーキテクチャ](architecture.md)

## コンセプト

夜の画面を、電子レンジたちが電子レンジらしいやり方で飛んでいく。鳥の翼を付けるのではなく、電子レンジの部品そのものを飛ぶための仕掛けにすることで、着想元と異なる独自の表現にする。

## 飛行表現の案

| 案 | 内容 | 長所 | 短所 |
| --- | --- | --- | --- |
| A. ドアの羽ばたき(採用) | 側面のヒンジでドアが開閉を繰り返し、羽ばたくように飛ぶ。窓からは回るターンテーブルと庫内の灯りが見える | 電子レンジ固有の部品で表現でき、着想元の鳥の翼と明確に異なる。ドアの開閉は横方向の拡大縮小で疑似的な立体感を出せ、実装が軽い | ドアが開いたときの庫内の描き込みが必要 |
| B. ターンテーブルのローター | 上部に出たターンテーブルがヘリコプターのローターのように回る | 回転だけで表現でき実装が最も簡単 | 電子レンジらしさがやや弱い。過去の紛争でプロペラへの変更が回避策になったとされ(二次情報)、似た印象を与えうる |
| C. 通気口のジェット | 背面の通気口から湯気を噴射して進む | 湯気の演出が映える | 湯気のパーティクル実装が必要。動きが単調になりやすい |

案Aを基本とし、窓の中でターンテーブルが回る演出を組み合わせて進める。

## 構成要素

| 要素 | 内容 | 導入 |
| --- | --- | --- |
| 本体 | 箱型の筐体。色違いを数種類用意する | Phase 3(Phase 1・2は仮の四角形) |
| ドア | 窓付き。開閉アニメーション | Phase 3 |
| 庫内 | ターンテーブルの回転、灯り | Phase 3 |
| 操作パネルとLED表示 | 7セグメント風の表示。現在時刻を出す(実物の電子レンジが待機中に時計を表示することから) | Phase 3 |
| 飛ぶ食べ物 | ポップコーンの袋、冷凍弁当、肉まん、温め直したマグカップなど | Phase 3 |
| 背景 | 黒を基本とし、夜空・時間帯による変化を追加 | Phase 4 |

## 素材の作り方

- 形式: SVG。テキストとして差分を確認でき、どの解像度でも鮮明に描ける。Inkscapeなどのオープンソースのツールで編集できる。
- 取り込み: 起動時にresvgでラスタライズし、テクスチャアトラスにする([アーキテクチャ](architecture.md#描画))。
- アニメーション: ドアなどの部品を別素材に分け、描画時に変形(横方向の拡大縮小・回転)で動かす。フレームごとの絵を大量に用意しない。
- 記録: 素材ごとの作者・ライセンス・出典を`assets/sprites/README.md`に記録する。

## 表現上のガイドライン

| ID | ガイドライン | 理由 |
| --- | --- | --- |
| G-1 | 着想元の名称・外観・音楽を使わない | [先行作品と知的財産上の配慮](../research/prior-art-and-ip.md)のIP-1〜IP-5 |
| G-2 | 危険な使い方(金属、殻付きの卵、密閉容器、生き物を入れるなど)を肯定的に描かない | 冗談として描いても実際の事故につながりうるため |
| G-3 | 画面全体の明滅や、1秒間に3回を超える閃光を使わない | 光過敏性発作への配慮。W3CのWCAG 2.3.1「3回の閃光、又は閾値以下」の考え方に倣う(調査時にはW3Cのページに接続できず、規格本文は未確認) |
| G-4 | 位置の変わらない要素を置かない。時計などの表示は動く電子レンジの上に置く | 有機ELディスプレイの焼き付き対策。焼き付きの防止はスクリーンセーバー本来の目的の1つである([仕様調査の要点](../research/windows-screensaver.md#要点)) |
| G-5 | 背景は暗い色を基本とし、明るい要素は小さくする | 夜間や暗い部屋でまぶしくしない |
| G-6 | 季節・記念日のテーマは設定でオフにできるようにし、特定の文化や宗教に偏らない構成にする | 利用者の多様性への配慮 |

## リポジトリのバナー

ルートのREADMEの先頭に置くバナー(`docs/assets/banner.svg`、1280×360のSVG)。2026-11-01に作った。スクリーンセーバーの見た目がまだ仮の段階なので、シンプルに作り、Phase 3で本番の素材ができたら作り直す。

- 内容: 夜空を、ドアを翼のように開いた電子レンジが右上へ飛ぶ(上の案A)。窓の中で庫内の灯りとターンテーブルが光り、操作パネルにLEDの時計がある。左に製品名と短い説明文を置く。
- 知的財産: 鳥の翼は付けず、電子レンジの部品(ドア)で飛ぶ姿にした(IP-2)。図形はすべてSVGで新たに描き、外部の素材は使っていない(IP-3)。着想元の名称やロゴは使っていない(IP-1)。
- 色: 背景は製品の背景色(`#060812`)から始まる夜空のグラデーションにした(G-5)。差し色は、庫内の灯りの橙と、ティール(`#5ee7df`)と紫(`#b490ff`)に絞った。
- 文字: SVGの`<text>`で書き、フォントは`Segoe UI`、`Helvetica Neue`、`Arial`、`sans-serif`の順に指定した。GitHubは画像としてSVGを表示するため、見る環境のフォントで描かれる。
- 確かめ方: ブラウザで描画して、文字と図形が重ならないことを確かめた。
