## 問題がなかったもの

- 履歴、ブランチ、タグ、`refs/pull`に、鍵やトークンの形の文字列は0件。`refs/pull`からだけ辿れるコミットは0件。
- Actionsのログに、トークン、鍵、メールアドレス(noreplyとexampleを除く)、セッションのID、ランナー以外のパスは0件。
- Issue、PR、コメントの書き手は、メンテナーとDependabotだけで、個人を特定できる値はなかった。
- 配布物に埋め込まれたパスは、ランナーのものだけ。PDBのパスはファイル名だけ。SBOMにアドレスもパスもない。
- 外部の人がメンションでエージェントを起動する経路は、いまはない(`@claude review`と`@claude steward`は、書き込みの権限を持つ人だけが使える。Claude Code GitHub Actionsのワークフローはない)。
- ワークフローは`pull_request_target`を使わず、トークンの権限は読み取りだけ。シークレットを使わない。アクションは3つともSHAで固定され、タグと一致した。
- 変更できないリリースは有効(15件のリリースはどれも変更できない)。
